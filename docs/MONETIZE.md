# 变现操作手册

代码已全部预置，**全部配置驱动、未配置即隐身**：不填任何 ID/凭据时，小程序没有广告、
无解锁门槛、比价链接为普通搜索链接——与送审版本行为完全一致。按下面步骤逐项点亮。

## 一、电商返佣 CPS（主通道，无 UV 门槛，上线即可做）

用户点比价按钮时带着明确购买意图，转成联盟推广链接即产生佣金（硬件约 1%~3%）。
与实时比价共用同一套联盟凭据，只需**额外加推广位 ID**：

| 平台 | 环境变量（加在云函数配置里，server 模式加在启动环境） | 申请 |
|------|------|------|
| 京东联盟 | 已有 `JD_APP_KEY/SECRET`，**新增 `JD_UNION_ID`**（联盟后台"我的-联盟ID"） | union.jd.com |
| 多多进宝 | 已有 `PDD_CLIENT_ID/SECRET`，**新增 `PDD_PID`**（推广位ID，格式 `12345_67890`） | jinbao.pinduoduo.com |
| 淘宝联盟 | 已有 `TAOBAO_APP_KEY/SECRET/ADZONE_ID`（返回的本就是推广链接，无需新增） | pub.alimama.com |

生效逻辑：取价时命中的最低价商品自动转推广链接（京东 `promotion.byunionid.get`、
拼多多 `promotion.url.generate`），比价按钮复制的就是带佣链接；**转链失败自动回退搜索
链接，绝不影响比价**。配好环境变量后重新部署云函数即生效，无需发版。

## 二、广告（流量主，需累计 UV ≥ 1000）

1. mp 后台「推广 → 流量主」开通 → 创建三种广告位，拿到 adUnitId；
2. 填进 `miniprogram/utils/ads.js` 的 `AD_UNITS`：

```js
const AD_UNITS = {
  splash: 'adunit-...',        // 开屏（用「原生模板」类型广告位）
  bannerTop: 'adunit-...',     // 明细页顶部横幅
  bannerBottom: 'adunit-...',  // 明细页/表单页底部横幅
  interstitial: 'adunit-...',  // 离开明细页插屏（每次启动最多1次）
  rewarded: 'adunit-...'       // 激励视频
};
```

3. 发版（加广告需重新审核）。

**已接好的广告场景**（对应 adUnitId 留空即关闭该项，布局参考通用工具类小程序）：

| 场景 | 类型 | 说明 |
|------|------|------|
| 启动开屏 | 原生模板（ad-custom） | 全屏白底 + 右上角 5 秒倒计时可随时跳过 + 底部品牌标识；每次启动最多 1 次，**广告加载失败立即放行** |
| 明细页顶部 | banner | 进页第一屏顶部展示位 |
| 明细页/表单页底部 | banner | 零件列表天然长滚动，不打扰 |
| 离开明细页 | 插屏 | 每次启动最多 1 次（频控写死在 ads.js） |
| 解锁预设角色（小雫/绫姐） | 激励视频 | 看完永久解锁（本地存储），galgame 皮肤逻辑 |
| 第 3 次起「换一套」 | 激励视频 | 每套新需求免费换 2 次，之后老板娘邀请看广告 |

**产品红线（写进代码的约定，改动前想清楚）**：
- 出方案、比价、口碑、对话这些**基础功能永远免费**，激励视频只锁增值体验；
- galgame 对话主界面不放 banner，沉浸感是产品的命；
- 广告拉取失败一律放行（视为已解锁），**广告故障绝不拦用户**；
- 激励承诺必须兑现（解锁即永久），否则流量主违规。

## 三、节奏

1. 审核期间：什么都不用动（本次代码默认隐身，不影响送审版）；
2. 上线当天：申请三家联盟（1~3 天下号）→ 配环境变量 → 重部署云函数 → CPS 开始积累；
3. UV ≥ 1000：开流量主 → 填 AD_UNITS → 发版；
4. 看数据调优：换一套使用频次决定 FREE_REGEN（chat.js 顶部常量），明细页停留时长决定 banner 去留。

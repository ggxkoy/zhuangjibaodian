# 个人主体无模型审核版

本分支用于个人主体小程序审核，微信端只提供结构化装机工具：

- 首页仅接收预算金额和固定用途选项；
- 推荐结果由固定硬件数据、接口兼容、功耗与预算规则计算；
- 结果页展示固定装机经验、人工审核过的口碑资料和价格查询结果；
- 小程序包不包含自由问答、自然语言解析、方案点评或模型调用模块；
- 云函数只保留 `config`、`recommend`、`prices` 三类确定性接口。

## 审核验收路径

1. 启动后直接进入“装机宝典”结构化表单页；
2. 选择预算与用途，点击“生成装机方案”；
3. 查看预算、配件、兼容性说明与价格信息；
4. 点击“换一套方案”验证固定规则可生成不同候选；
5. 全流程不存在聊天输入、角色对话或模型生成内容。

企业主体版本如需恢复原有模型功能，可从提交 `204e9ce` 或原功能分支继续开发。
